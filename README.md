DevSecOps

This repository contains DevSecOps resources, automation snippets, and guidance to help integrate security into development and operations workflows.

Contents

- Security-as-code examples (IaC scanning, policy as code)
- CI/CD pipeline templates with security gates
- Playbooks for incident response and secrets management

Quickstart

1. Review the pipeline templates in the `ci/` directory.
2. Run linters and security scanners locally (recommended: `snyk`, `tfsec`, `trivy`).
3. Integrate the provided pipeline templates into your CI system and enable the security checks.
